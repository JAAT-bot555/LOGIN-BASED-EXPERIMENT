# Login Form with Role-Based Message

## Aim
To implement a React login form with Admin and Viewer roles using state management and conditional rendering.

## Features
- Username input
- Login as Admin / Login as Viewer
- Welcome message with username and role
- Admin: Delete Post
- Viewer: Read-only access
- Logout returns to login form
- Clean responsive UI

## Run
```bash
npm install
npm start
```

## Demo
1. Enter a username.
2. Click Login as Admin and demonstrate Delete Post.
3. Click Logout.
4. Enter a username again.
5. Click Login as Viewer and demonstrate Read-only access.
6. Click Logout.

## Concepts
React, useState, props, conditional rendering, role-based UI.
